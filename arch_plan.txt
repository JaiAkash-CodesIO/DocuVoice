================================================================================
                        Processing Pipeline Stages
================================================================================

1. Ingestion:
   - Validates file formats (.pdf, .png, .jpg, .jpeg) and size (< 10 MB).
   - Generates unique UUID tracking key for safe multi-tenant file handling.

2. Preprocessing:
   - Aspect-ratio preserving normalization to optimal target width (1600px).
   - PyMuPDF rasterization for multi-page PDF documents.
   - Grayscale conversion for maximum OCR character contrast.

3. Region-Aware Multi-Pass OCR:
   - Extracts page-level text and word bounding coordinates.
   - Multi-mode PSM evaluation to maximize confidence scores.
   - Separates tabular and columnar structures from unstructured body text.

4. Extraction & Normalization:
   - Document type identification (Invoices, Receipts, Resumes, Certificates).
   - Structured key-value pair discovery.
   - Regex entity recognition (Emails, Phone numbers, Dates, URLs).
   - Dynamic table matrix reconstruction.
